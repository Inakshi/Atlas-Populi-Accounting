# Finance reference documents

This folder contains the finance documentation that existed before the current repository structure was introduced. It remains available as reference while enduring content is reviewed and placed in the appropriate `context/`, `policies/`, `processes/`, `skills/` or `agent-team/` location.

New operating guidance should use the agreed structure and follow the [Documentation Framework](../documentation-framework.md). Do not treat an older document here as authoritative when a maintained policy, SOP or skill covers the same subject.
